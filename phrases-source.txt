# phrases-source.txt — the corpus for Punctuators' "Restore the Phrase" mode.
# Design: docs/punctuators-ladder.md §11.3–§11.5.  Draft 2026-08-22, awaiting the dev's prune.
#
# BUILD    python3 build-ladders.py --phrases           writes phrasePOJO.js, rewrites the '#~'
#          python3 build-ladders.py --phrases --check   report only, writes nothing
#
# FORMAT   One saying per line:   <phrase with {braces}> | <origin>
#          {braces} mark the words the puzzle is ALLOWED to shift along the ladder.
#          Everything else on the line is left alone.
#
#          {word}            the build picks the direction and the rung
#          {word>child}      narrow to THIS child — use it when the build's pick is obscure
#                            (basket → "frail"); a wrong child errors and lists the real ones
#          {word^}           broaden — never narrow this one
#          {word+}           the word is plural though it doesn't look it, so shift it plural
#                            ("plenty of {fish+}" -> sharks, but "a {fish} out of water" -> shark)
#          {{word}}          shift 2 rungs instead of 1 (a harder day). None used yet.
#
# LINES    '#'  a comment you wrote.   '#~' an annotation the build wrote — see below.
#
# YOUR JOB IS TO PRUNE, NOT TO RESEARCH.  Under each phrase, '#~' shows what the built
# ladder ACTUALLY does with that word — the rung above it and the rungs below it, taken
# live from ladderPOJO.js — and then, on the '=' line, THE PUZZLE IT MADE.  Read that line
# and ask one question:
#
#     Would a player see that and think "oh, it's <the saying>"?
#
# If yes, leave it.  If the shifted word is the wrong SENSE of the word, delete its braces
# (keep the phrase — an unbraced word is simply never shifted).  If it's the right sense but
# an obscure rung, pin a better one with >child.  If a phrase has no braces left, delete the
# whole line.  This is the one judgment no script can make; see the doc §11.4 for why.
#
#   ↕ = the word can shift both ways      ↑ = broader only      ↓ = narrower only
#   = = the generated puzzle              ! = something the build had to work around
#
# Known rough edges the build can't see, all fixable from this file:
#   a mass noun shifting to a count noun ("Don't play with bonfire" wants "a bonfire")
#   a plural-only key broadening to a singular ("A building of meld" <- {cards})
#   an obscure child the ordering floated to the front ({basket} -> frail) — pin it with >child
#
# Already dropped in drafting, as examples of the trap:
#   "Don't count your chickens"      chicken → MEAT → food   (the saying means the bird)
#   "A needle in a haystack"         needle → LEAF           (the pine needle)
#   "The tip of the iceberg"         iceberg → LETTUCE       (yes, really)
#   "A heart of gold"                heart → suspicion → notion (the organ isn't the best sense)
#   "You can't have your cake…"      cake → block            (true, reads as nonsense)
#
# '#~' lines are REGENERATED by `build-ladders.py --phrases`. Don't hand-edit them;
# edit the phrase line above them and re-run.
