Export & import

Everything autosaves to localStorage as you draw, so a refresh is safe — but a reference image is held in memory only and won't survive one. Drop a .json or an image anywhere on the page. Empty targets are skipped on export. Guide letters are never exported — they are scaffolding, not target data — so they survive a refresh but not a round-trip through a downloaded file.
